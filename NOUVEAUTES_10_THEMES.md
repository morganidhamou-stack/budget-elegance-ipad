# Budget Élégance — 10 thèmes

Les six thèmes initiaux restent disponibles : Rose poudré, Bleu océan, Vert sauge, Graphite, Sable & terracotta, Nuit élégante.

Nouveaux styles : Atelier éditorial (magazine et encre), Aurora glass (surfaces vitrées), Terminal pro (grille et typographie technique), Solstice (géométrie solaire).

## Installation

Remplacez votre projet source par les fichiers de cette archive ou, pour une mise à jour minimale, remplacez uniquement `src/App.jsx` et `src/style.css`. Vos données Tauri enregistrées localement ne sont pas dans le dossier source. **Effectuez néanmoins une sauvegarde JSON avant toute mise à jour.**

Windows : `npm install` puis `npm run tauri dev`. Compilation : `npm run tauri build`. GitHub Actions est conservé pour Mac Intel / Apple Silicon et Windows.

## Vérification

Les contrastes ont été corrigés au niveau des variables et des sélecteurs CSS, en particulier pour Nuit élégante et Terminal pro. La compilation native macOS doit être vérifiée dans GitHub Actions.
