# Budget Élégance — report mensuel et thèmes

- Les quatre indicateurs d’origine restent présents.
- Solde restant : report du mois précédent + revenus - dépenses - versements d’épargne + retraits d’épargne.
- Épargne : cagnotte cumulée (versements moins retraits).
- Une nouvelle opération « Retrait épargne » est disponible, y compris dans les opérations récurrentes.
- Le report et les mouvements d’épargne du mois sont affichés sous les quatre indicateurs.
- Les quatre thèmes Nordic Calm, Luxe noir & or, Glass Premium et Art déco disposent de compositions et composants plus différenciés.
- Contrastes renforcés pour Luxe noir & or.

**Attention** : le calcul reprend toutes les opérations enregistrées et les abonnements actifs depuis leur date de début. Si le compte existait déjà avant les premières opérations saisies, il faut tenir compte du solde initial (`balance` dans la sauvegarde JSON). Exportez une sauvegarde avant toute mise à jour.
